מע"מ ומספור מסמכים
סנכרון לגוגל דרייב

מאפשר לראות ולעדכן את הנתונים גם מהטלפון וגם מהמחשב, דרך קובץ גיבוי אחד שנשמר בגוגל דרייב שלך (רק שלך — לא של FlowCRM). זו לא חובה: האפליקציה ממשיכה לעבוד מצוין גם בלי זה, עם הורדת גיבוי ידנית בלבד.

איך מגדירים את זה? (חד־פעמי, כמה דקות)
  1. כנסו ל־console.cloud.google.com עם חשבון הגוגל שלכם ולחצו "צור פרויקט" (New Project) — כל שם, למשל "FlowCRM".
  2. בתפריט: APIs & Services > OAuth consent screen. בחרו External, מלאו שם אפליקציה ואימייל, שמרו (אין צורך לשלוח לאישור גוגל — מספיק שהחשבון שלכם רשום כ"בודק/Test user" באותו מסך).
  3. APIs & Services > Library — חפשו "Google Drive API" ולחצו Enable.
  4. APIs & Services > Credentials > Create Credentials > OAuth client ID. סוג: Web application.
  5. תחת "Authorized JavaScript origins" הוסיפו את הכתובת המדויקת שבה האתר רץ (למשל https://glidingforce.github.io) — בלי סלאש בסוף.
  6. לחצו Create — תקבלו "Client ID" שנראה כמו 123...apps.googleusercontent.com. הוא לא סודי; הדביקו אותו כאן למטה.

גיבוי ושחזור ידני

כל הנתונים נשמרים בדפדפן הזה בלבד. גם אם מפעילים סנכרון לדרייב למעלה, מומלץ להוריד גיבוי מדי פעם כרשת ביטחון נוספת.
