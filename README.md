# אחזקה פלוס — מערכת מסמכים עצמאית

אפליקציית ווב עצמאית (ללא שרת) ליצירת חשבוניות עסקה, קבלות והצעות מחיר,
עם ייצוא PDF אמיתי (הדפסת הדפדפן), בעברית ו-RTL מלא.

## איך זה עובד

- כל הנתונים (לקוחות, מסמכים, הגדרות) נשמרים **בדפדפן של המכשיר שלך**
  (localStorage) — שום דבר לא נשלח לשרת שלנו.
- קובץ ה-PDF נוצר באמצעות הדפסת הדפדפן (Ctrl+P / שיתוף ← הדפסה), בדיוק כמו
  Word או Google Docs — לא צילום מסך, אז אין עוד עמודים חתוכים או קבצים
  ברזולוציה נמוכה.
- **סנכרון בין מכשירים (אופציונלי):** הגדרות ← סנכרון לגוגל דרייב. אחרי
  התחברות חד־פעמית עם חשבון Google, האפליקציה שומרת קובץ גיבוי אחד
  ("FlowCRM Backup.json") בדרייב שלך ומעדכנת אותו אוטומטית בכל שינוי, וגם
  מושכת עדכונים כשפותחים את האתר ממכשיר אחר. זה עדיין ללא שרת משלנו — ההתחברות
  והתקשורת עם גוגל דרייב קורות ישירות מהדפדפן. שימו לב: זה "מי ששמר אחרון
  מנצח" ולא מיזוג חכם, אז עדיף לא לערוך בו-זמנית משני מכשירים. גם בלי
  להפעיל את זה, אפשר להמשיך להוריד גיבוי ידני (הגדרות ← גיבוי ושחזור ידני).

## הפעלה מקומית (לבדיקה)

```
python3 -m http.server 8000
```
ואז פתחו http://localhost:8000

## פרסום ב-GitHub Pages

1. Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`.
2. האתר יהיה זמין בכתובת `https://<username>.github.io/<repo-name>/`.
3. בטלפון: פתחו את הכתובת ב-Chrome/Safari ← תפריט ← "הוסף למסך הבית", כדי
   שהאפליקציה תיפתח כמו אפליקציה רגילה.

## מבנה הקבצים

- `index.html` — לוח בקרה
- `documents.html` — רשימת מסמכים
- `clients.html` — ניהול לקוחות
- `create.html` — יצירת/עריכת מסמך
- `view.html` — תצוגה להדפסה / PDF
- `settings.html` — פרטי החברה, מספור מסמכים, גיבוי
- `app.js` — שכבת הנתונים המשותפת
- `drive-sync.js` — סנכרון אופציונלי לגוגל דרייב
- `style.css` — עיצוב משותף
